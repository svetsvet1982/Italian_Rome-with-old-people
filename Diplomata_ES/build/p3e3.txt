+ carta explicativa = 설명서. 사과 대신 쓰는 공식 문서

+ romper aguas = 양수가 터지다. 출산 시작을 알리는 표현
+ estar de parto = 분만 중이다. 'ponerse de parto'는 진통을 시작하다
+ control de acceso = 출입 통제. 항구 보안 절차
+ siempre que + 접속법 = ~하는 한. 조건을 제한하는 접속사구

+ guardar para = ~을 위해 아껴 두다. 'guardar para esta ocasión'
+ estar a punto = 막 ~하려는 참이다. 'estás a punto'
+ hospital = 병원. 'directas al hospital'

ÁLVARO: Un gobernador prudente. ||| 신중한 총독이군요.

## 서점 옥상 — LA AZOTEA DE HAMID

HAMID: Quiero regalarle una cosa. Tenga. ||| 선물을 하나 주고 싶네. 받게.
ÁLVARO: Es un «Quijote». ||| 『돈키호테』군요.

ÁLVARO: Argel, mil quinientos setenta y cinco. Lo sé. Ayer lo leí en un libro de cuentas. ||| 알제, 1575년. 압니다. 어제 장부에서 읽었습니다.
HAMID: Entonces ya lo sabe todo. Solo falta llevarlo a casa. ||| 그럼 다 아는군. 집으로 가져가기만 하면 되네.
## 보고 — EL INFORME
ÁLVARO: Presidente Calvo, perdone la hora. Le llamo para informarle de una gestión que he hecho esta semana. A título privado, como siempre. ||| 칼보 위원장님, 시간이 늦어 죄송합니다. 이번 주에 한 일을 보고드리려 전화했습니다. 늘 그렇듯 개인 자격으로요.

ÁLVARO: ¿Dónde? ||| 어디입니까?

ÁLVARO: Eso no estaba en el libro de los frailes. ||| 수사들의 책에는 없던 내용이군요.

+ asiento = 장부의 기장 항목. 'primer asiento', 'segundo asiento'

+ quedar empatados = 비기다. 'empate'는 동점
+ por si acaso = 혹시 몰라서. 선물에 붙이는 겸양의 말
+ misión de verificación = 검증단. EU가 파견하는 감사 인력
+ una cuenta abierta = 열린 장부. 여기서는 배의 억류 상태를 가리키는 은유
+ La libertad, Sancho = 『돈키호테』 제2부 58장. 세르반테스가 알제 포로 생활(1575–80)을 겪은 뒤 쓴 구절
+ Hace frío = 춥다. 다음 화 울란바토르의 복선
