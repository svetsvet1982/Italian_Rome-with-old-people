# 이탈리아어 대화문 기획서 — 《Il Circolo del Terzo Giovedì》(셋째 목요일 독서 모임)

## 0. 한 줄 콘셉트
밀라노 브레라 지구의 작은 서점에서 매달 열리는 이탈리아 문학 독서 모임. 그곳에서 만난 두 사람이 문학 구절을 매개로 말다툼하고, 가까워지고, 흔들리고, 마침내 연인이 되어 함께 서점을 여는 1년간의 이야기.

## 1. 분량·구조
| 항목 | 규격 |
|---|---|
| 구성 | 4부 × 16화 = 64화 |
| 1화 분량 | 100턴 (턴 = 화자 1회 발화, 번호 매김) |
| 총 분량 | 6,400턴 (약 11만 단어 추정, 1턴 평균 15~20단어) |
| 인용 | 화당 필수 1회 + 선택 1회(총 1~2회). 대화 안에서 인물이 직접 낭독·암송·논쟁 |
| 화 말미 | **한글 해설 블록**: 원문 / 출처 / 한글 번역 / 쓰인 맥락(작품 속 맥락 + 대화 속 맥락) / 어휘·문법 노트 |
| 레벨 | 1부 A2→B1, 2부 B1, 3부 B1→B2, 4부 B2→C1 (어휘·문장 길이·접속법 비중을 점진적으로 상승) |

## 2. 등장인물
| 인물 | 설정 |
|---|---|
| **Anna Rinaldi** (32) | 브레라 미술관 소속 회화 복원사. 베르가모 출신. 정확하고 신중, 말보다 손이 먼저. 전 연인과의 이별 후 마음을 닫음. 《I promessi sposi》를 "지루한 교과서"로 기억하다 모임에서 재발견 |
| **Matteo Colombo** (36) | 구조 엔지니어. 레코 출신(만초니의 호수 마을). 겉은 실용적이나 몰래 시를 씀. 책 여백에 메모하는 습관 |
| **Signora Valeria Sormani** (74) | 은퇴한 문학 교사, 모임의 창립자·진행자. 두 사람의 조력자 |
| **Professor Bruno Gatti** (68) | 단테 광. 모든 대화를 《신곡》으로 끌고 감 (코믹 릴리프) |
| **Chiara Beltrami** (24) | 문학과 대학원생. 아이러니, 현대 문학 담당. 두 사람의 관계를 가장 먼저 눈치챔 |
| **Davide Ferri** (45) | 서점 주인. 3부 말~4부에서 서점 인수 제안 |
| **Karim Haddad** (38) | 이집트계 밀라노인 번역가. 외국인 시각으로 이탈리아어를 관찰 |
| **Riccardo Sala** (34) | Anna의 전 연인. 2~3부 갈등 촉매 |
| **Nonna Teresa** (88) | Matteo의 할머니. 사랑 이야기·속담 담당 |

화법 장치: 초반엔 서로 **Lei**(경어) → 6화에서 **tu**로 전환(학습 포인트) → 이후 감정 고조 때만 일시적 Lei 복귀(거리두기 표현). 밀라노 색채는 소량의 방언 어휘(*sciura, ghe pensi mi*, *navigli*, *aperitivo* 문화)로 가볍게 가미.

## 3. 4부 개요
| 부 | 제목 | 계절·시기 | 관계 곡선 |
|---|---|---|---|
| 1부 | **Selva oscura** (어두운 숲) | 10~12월 | 첫 만남 → 티격태격 → 친구 → 연말 아슬아슬한 설렘 |
| 2부 | **Tanto gentile e tanto onesta** | 1~3월 | 깊어지는 대화 → 가족 소개 → 오해·질투 → 첫 키스 → 공식 연인 선언 |
| 3부 | **Pace non trovo** (평화를 찾지 못해) | 4~6월 | 연애의 일상 → 진로 충돌(Matteo 로테르담 제안 / Anna 로마 발령) → 큰 싸움·별거 → 편지·재회·타협 |

2. **배치 집필**: 부 단위(16화)로 진행. 부 시작 전 *어휘·문법 포인트 표*와 *복선 표*(소품, 책, 말버릇) 작성.
3. **파일 규격**: `milano/{부}부{화}화_{이탈리아어제목}.md`, 헤더에 부/화, 장소, 시간, 등장인물, 레벨, 인용 목록. 턴은 `01. ANNA: …` 형식.
4. **한글 해설 블록**(화 말미): ① 원문 ② 작가·작품·연도 ③ 한글 번역 ④ 작품 속 맥락 ⑤ 대화 속에서 이 구절이 쓰인 이유 ⑥ 핵심 어휘·문법.
5. **복선·수미상관**: 1화 만초니 첫 문장 ↔ 64화 재호출, "여백의 메모" 소품(10·42·60화), 서점 의자 하나(1·58·62화).

## 6. 위험·유의사항
- **인용 정확성**: 위 인용은 기획용 후보이며 집필 시 정본과 대조해 철자(고어 표기: *ò, et, ch'*)와 행 구분을 확정한다. 확신이 낮은 항목(41화 메리니, 54·59화 만초니, 60화 마키아벨리, 18화 사바)은 우선 검증 대상.
- **저작권**: 20세기 작가(웅가레티, 몬탈레, 콰시모도, 파베세, 칼비노, 에코, 사바, 메리니 등)는 보호기간 내일 수 있으므로 1~3행 이내 짧은 인용과 해설 목적에 한정하고, 번역은 새로 직접 번역한다.
- **레벨 조정**: 100턴은 길어 반복이 생기기 쉬우므로 화마다 *상황 어휘 주제*(카페, 복원, 병원, 계약 등)를 고정해 반복을 방지.
