# DUE SPONDE (두 해안) — 이탈리아어판 시리즈 바이블
빌드: build/mk.sh <부> <화> "<파일명>" · 점검: python3 build/check.py <파일들>

## 고정 설정
- 주인공 코라도 란차(46) — 이탈리아 외무부(파르네지나) 위기대응국 협상관. 나폴리 출신, 제과점 집안. 몸짓과 농담이 많고 '식탁에서 합의가 된다'가 철학. 몰래 걱정이 많고, 화가 나면 표준 이탈리아어가 사투리로 바뀐다.
- 조울리아 마르케티(30): 분석관. 볼로냐 출신, 문서와 숫자에 강한 실무형
- 비토리오 산드리 대사(70): 은퇴 대사, 스승. 역사 일화를 에스프레소 한 잔 분량으로 들려준다
- 에토레 벨란디 몬시뇰(66): 바티칸 외교관, 오랜 친구. 비공식 채널의 문지기
- 페데리카 루스폴리(44): 대외정보기관(AISE) 연락관. 늘 대가를 청구하는 공급자
- 체사레 비탈레(51): 외무사무총장, 라이벌. 승진을 위해 침묵을 파는 사람
- 레오 란차(15): 아들. 학교 철학 수업의 질문으로 아버지를 멈춰 세운다
- 테스타초 보치아 클럽 노인들: 에르콜레, 페피노, 노나 콘체타. 로마의 기억이자 해법의 단서
- 세계: 가상국: 타르시아 공화국(북아프리카 섬 국가), 만다 공화국(사헬 내륙), 로마 정상회의. 실제 정치인 실명은 쓰지 않는다. 역사 사례(로디 평화, 로렌초의 나폴리 방문, 오시모 조약, 우찰레 조약 등)는 실제 사건을 인용한다.
- 수준: B2–C1 (외교·법률 어휘, 접속법, 관용구, 사투리 한 줄 주석)
- 스타일: 지문 없이 대사만. 이탈리아어 + 한국어 대역 + 주석. 존칭 Lei와 친근한 tu의 전환, 몸짓 어휘, 제스처 표현을 학습 포인트로.

## 형식 규칙(반드시)
- 지문 없이 대사만. `NOME: 이탈리아어 ||| 한국어` (화자 이름은 이탈리아어식 대문자 CORRADO, GIULIA 등, 30자 이내). 한 줄=한 턴.
- 파일 머리: @series DUE SPONDE · 외교관 시리즈 / @lang 이탈리아어 낭독 교재 / @part / @ep / @title(이탈리아어) / @ko / @setting / @level B2-C1 / @cast NOME | 설명 … / @note(역사 논거·어휘, 한국어) / @next
- 섹션 `## 장면명 — SCENA` 4~6개, 섹션 끝 `+ 표현 = 설명` 5~8개(접속법·관용구·Lei/tu 전환·사투리 한 줄 설명).
- 한 화 100~190턴(권장 130~160). 한국어는 자연스러운 구어체. 역사 사례는 실제 사건을 대사 속 논거로 쓰고 사실 오류 금지(확신 없으면 일반화). 실존 정치인 실명 금지.
- 이 시리즈 중심 장치: 식탁·음식·몸짓 어휘, 보치아 클럽 노인들의 입담, 아들 레오의 철학 질문, 스승 산드리의 에스프레소 일화. 다른 시리즈(스페인/네덜란드/러시아) 장치 금지.

## 4부 «L'isola che nasce» (태어나는 섬) — 한 사건, 12화 (3부 1년 뒤)
- 기획: ../Diplomata_Plans/part4_plans.md '2. 이탈리아어' 절(12화 표·결말 구상). 연속성: build/facts_P1a/b, P2a, P3a, P3b.
- 란차 48(위기대응국장 대행), 레오 17(리체오), 노인들=보치아 클럽 '위원회'(성: 에르콜레 산티니, 페피노 콘티, 콘체타 모레티). 3부 말미 단서: 테베레 수드 스빌루포→메리디아나→레오나르도 홀딩, 49% 신탁 기한 12개월, 사아디의 음성 메시지 '마르사 베이다 남쪽 해저가 솟는다'.
- 해법 원리: 먼저 깃발을 꽂지 않는 쪽이 이긴다 → 소유 아닌 '번갈아 쓰는 권리'(지분이 아니라 계절) → 사라진 섬에 이름을 남기지 않는 합의. 마지막 화에서 레오가 합의문을 식탁에서 낭독하고 첫 잔을 든다.
