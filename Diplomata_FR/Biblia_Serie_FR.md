# LA NUANCE (뉘앙스) — 프랑스어판 시리즈 바이블
빌드: build/mk.sh <부> <화> "<파일명>" (원고 build/p<부>e<화>_a/b.txt) · 점검: python3 build/check.py <파일들> ('NO CYRILLIC' 메시지는 무시)

## 고정 설정
- 주인공 쥘리앵 들로름(1부 46세 → 3부 46~47 → 4부 47): 프랑스 외무부(케도르세) 중재조정실 부실장(4부에서 실장). 리옹 출신, 부숑(전통 식당) 집안의 아들. 데카르트식 논리, 날카로운 유머, '다코르, 메(D'accord, mais…)' 화법. 흥분하면 목소리를 낮추고 말이 더 정확해진다. 아내는 이혼/별거 언급 최소.
- 카미유 루셀(30): 분석관, 마르세유 출신 법학자, 문서의 뉘앙스에 강한 실무형. 들로름에게 vous, 점차 tu로.
- 앙리 드 발쿠르 대사(73): 은퇴 대사, 스승. 치즈 카트 앞에서 역사를 들려준다(치즈 카트 일화 = 에스프레소·사모바르 대신 이 시리즈 고유 장치).
- 엘렌 뒤프렌(43): 대외안보총국(DGSE) 연락관. 정보를 팔고 사는 현실주의자, 늘 대가 청구.
- 베르트랑 르포르(51): 장관 비서실장, 라이벌. 형식과 위계로 사람을 묶는다.
- 레아 들로름(16): 딸. 철학 시험 준비. 질문마다 '그건 개념 정의의 문제예요'라고 되받는다.
- 세계: 가상국: 카스라 에미르국(걸프형 소국), 생토뱅 군도(프랑스 해외 영토)와 인접국 말라비 공화국, 베르사유 정상회의. 가상 단체 '발루아 어드바이저리'(1부 말 등장, 2부에서 실체). 실제 정치인·기업 실명 금지. 역사 사례는 실제 사건만 인용(아미앵의 판결, 웨스트팔리아, 탈레랑, 파쇼다, 앙탕트 코르디알 등).
- 수준: B2–C1 (외교·법률 어휘, 접속법, 뉘앙스 표현, tu/vous 전환).
- 시리즈 고유 장치: 한 단어의 뉘앙스(번역·판본 차이), 치즈 카트·식탁의 프랑스 요리, 'D'accord, mais…', 레아의 철학적 정의 질문, 발쿠르의 역사 일화. 다른 시리즈(이탈리아 보치아, 스페인, 네덜란드, 러시아 사모바르) 장치 금지.

## 형식 규칙(반드시)
- 지문 없이 대사만. `NOM: 프랑스어 ||| 한국어` (화자 이름은 프랑스어식 대문자 JULIEN, CAMILLE 등, 30자 이내, 콜론은 화자 뒤 한 번). 한 줄 = 한 턴. 대사는 프랑스어 정자법(악센트) 정확히.
- 파일 머리: @series LA NUANCE · 외교관 시리즈 / @lang 프랑스어 낭독 교재 / @part / @ep / @title(프랑스어) / @ko / @setting / @level B2-C1 / @cast NOM | 설명(한국어) … / @note(역사 논거·어휘 안내, 한국어) / @next
- 섹션 `## 장면명 — SCÈNE` 4~6개, 섹션 끝 `+ 표현 = 설명` 5~8개(접속법·뉘앙스·tu/vous 전환·관용구).
- 한 화 100~190턴(권장 130~170). 한국어는 자연스러운 구어체. 역사 사례는 대사 속 논거, 사실 오류 금지(확신 없으면 일반화). 한 화 = 한 협상 단위 + 해법의 순간 1개.


## 1부 «Le Troisième Texte» (제3의 문서)
- 사건: 걸프의 소국 카스라가 프랑스 조선소의 기술자 14명을 계약 분쟁으로 억류한다. 핵심은 프랑스어·아랍어·영어 세 판본의 미세한 차이.
- 핵심 단서: 계약의 '부속 서한'에만 있는 한 단어: 프랑스어판 'engagement'(약속)과 아랍어판의 '의무'
- 해법/전개: 세 판본을 정렬한 '공동 번역 위원회'와 수수료 투명화. 르포르의 형식 조작이 드러남
- 다음 부 연결: '발루아 어드바이저리'라는 이름(2부 연결)

## 2부 «L'Archipel de Saint-Aubin» (생토뱅 군도)
- 사건: 해외 영토 생토뱅 군도를 인접국 말라비가 영유권 문제로 제기한다. 1962년 비공개 서한이 쟁점이 된다.
- 핵심 단서: 독립 직전 교환한 서한: 해저 자원 개발권을 '공동 관리'하기로 한 비공개 약속
- 해법/전개: 영유권은 건드리지 않고 '공동 개발 협의회' 구성. 스승 발쿠르가 증언의 대가를 치름
- 다음 부 연결: 발루아 어드바이저리의 실체


## 3부 «Le Sommet de Versailles» (베르사유 정상회의)
- 사건: 베르사유 궁에서 열리는 유럽·아프리카 정상회의. 거울의 방에서 합의문 서명 직전, 조항 하나가 바뀐다.
- 핵심 단서: '부록 7': 데이터·AI 협력 조항에 삽입된 감시 허용 문구
- 해법/전개: 원문과 수정 이력을 공개하는 투명 절차. 들로름의 결산
- 다음 부 연결: 시리즈 결산: 한 단어를 지키는 일이 평화를 지키는 일
