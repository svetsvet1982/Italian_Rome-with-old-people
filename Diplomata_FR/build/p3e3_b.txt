+ Qui ne dit mot consent. = 말하지 않는 자는 동의한 것이다. 침묵을 동의로 보는 법언인데, 말한 사람이 있었다면 성립하지 않음
+ mettre en forme / mise en forme = 정리하다 / 정리. 모든 것을 가릴 수 있는 완곡한 행정 표현
+ une mise sous tutelle / une mise sous lumière = 후견 상태에 두기 / 조명 아래 두기. 쥘리앵의 말놀이로 통제와 투명성을 구별
+ J'accuse les chiffres. = 저는 숫자를 고발합니다. 사람을 비난하지 않고 기록으로 말한다는 방식
+ une copie certifiée = 인증 사본. 의전 책임자의 도장으로 증거 가치를 보태는 사본
+ une session se ferme / s'ouvre = 세션이 닫히다 / 열리다. 접속 기록의 시각이 지운 시점을 짐작하게 하는 단서
+ lecture seule = 읽기 전용. 수정 권한 없이 모두가 이력을 열람하도록 하는 설정
+ garder un nom = 이름을 지키다. 직업적 손실을 감수하고 양심을 택하는 사람에게 쥘리앵이 건네는 말

MBARGA: Oui. ||| 예.
