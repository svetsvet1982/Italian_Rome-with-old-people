+ een zwijger / zwijgen = 침묵하는 사람 / 침묵하다. 오라녜 공 빌럼의 별명과 이어진다

+ de moed hebben = 용기를 내다
+ doorlopen = (이자가) 계속 붙다. 'een rente die doorloopt'

+ as = 재. 'tot as verbranden'은 재가 되도록 태우다
+ iets bewaken = ~를 지키다, 감시하다
+ vertrouwen tot = ~까지 믿어 주다
+ een belofte / een intentie = 약속 / 의도. 요스트가 둘을 구분한다
+ het telefoontje = (짧은) 전화 한 통. '-je' 지소형
